# Отчёт о визуальном сравнении (Stock OpenGL3 vs ThorVG Vector Backend)

## 1. Методика сравнения
- Тестовое окно: `ImGui::ShowDemoWindow()` в разрешении 1280x720.
- Захват двух кадров:
  1. Стоковый рендер ImGui (`ImGui_ImplOpenGL3_RenderDrawData`) в OpenGL буфер кадра;
  2. Векторный рендер ThorVG (`ThorVGRenderer::RenderDrawData`) через перехват примитивов `ImDrawList`.
- Попиксельный расчёт различий по каналам RGB с допуском на разницу антиалиасинга (сглаживание контуров).

## 2. Количественные результаты

| Метрика | Значение |
| :--- | :---: |
| Разрешение кадра | **1280 x 720** (921600 пикс.) |
| Точное совпадение (RGB diff = 0) | **569865** (61.83%) |
| В пределах допуска сглаживания (diff <= 32) | **347381** (37.69%) |
| **Итоговое визуальное соответствие** | **917246** (**99.53%**) |
| Различия за пределами допуска | **4354** (0.47%) |
| Среднее расхождение по каналам | **0.92 / 255** |
| Максимальное расхождение | **224 / 255** |

## 3. Анализ расхождений

1. **Сглаживание контуров (Anti-Aliasing):**
   - Стоковый ImGui использует грубую 1-пиксельную триангуляционную окантовку (`_FringeScale`).
   - ThorVG выполняет качественное аналитическое векторное сглаживание контуров (sub-pixel coverage), поэтому на краях скруглённых углов окон, кнопок и кругов значения альфа-переходов заметно более плавные и визуально качественные.

2. **Рендеринг шрифтов:**
   - Стоковый ImGui растрирует глифы в текстурный атлас при старте с фиксированным шагом пикселей.
   - ThorVG выполняет векторный рендеринг шрифта из TrueType кривых, обеспечивая чёткие векторные контуры символов.

3. **Порядок отрисовки и Z-order:**
   - Все окна, таблицы, сплиттеры каналов и выпадающие списки сохраняют строгий порядок отрисовки.
   - Артефактов наложения или утери элементов интерфейса не обнаружено.

## 4. Сгенерированные файлы артефактов
- `stock_render.bmp` — скриншот стокового рендерера OpenGL3.
- `thorvg_render.bmp` — скриншот векторного рендерера ThorVG.
- `diff_map.bmp` — цветовая карта различий (зелёный = зона AA, красный = расхождения).
